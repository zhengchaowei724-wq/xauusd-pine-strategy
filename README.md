# xauusd-pine-strategy
High-quality intraday TradingView Pine Script v6 strategy for XAUUSD with ATR stop loss and take profit.

## Download a popular GitHub trading agent

I added a helper script to download the `TauricResearch/TradingAgents` repository:

```bash
./scripts/download_trading_agent.sh
```

Optional: choose your own target directory:

```bash
./scripts/download_trading_agent.sh my-trading-agent
```
